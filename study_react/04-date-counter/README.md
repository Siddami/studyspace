# Date Counter
This is a mini React project that calculates dates by adding or subtracting a number of days from a given starting date.

It includes a step-based counter, allowing users to:

1. Set the number of steps to increment or decrement

2. Adjust the day count accordingly

View the resulting date based on the counter

# Features
- Dynamic counter to adjust the number of days

- Plus(+) and minus(-) Step controller to determine how much the counter changes

- Real-time display of the resulting date based on the current count

- Inline styling using the style attribute

# What I Learned
During this project, I practiced and learned:

1. State management in React using the useState hook

2. Conditional rendering based on state values
